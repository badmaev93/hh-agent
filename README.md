# hh-agent

Автономный поиск и отклик на вакансии hh.ru через [Claude Code](https://claude.com/claude-code) + браузерную автоматизацию (Playwright). Официальный API hh.ru для соискателей закрыт с 15.12.2025 — работать приходится через тот же браузер, каким пользуется человек.

Что умеет:
- Ищет вакансии несколькими формулировками запроса сразу (не пропускает синонимы должности/стека).
- Сопоставляет каждую вакансию с твоим резюме и оценивает релевантность 0-10 (параллельно, субагентами).
- Ранжирует топ-50 кандидатов на отклик и показывает список на подтверждение — ничего не отправляет без "ОК".
- Пишет сопроводительные письма под конкретную вакансию и полирует их через скилл [ai-copywriter](https://github.com/mikiarlo3/ai-copywriter), чтобы не звучали как шаблон.
- Отправляет отклики с анти-бан паузами (20-60с между откликами, лимит на прогон).
- Замечает вакансии с доп. анкетой работодателя (зарплата, скрининг-вопросы) и НЕ угадывает ответы — либо спрашивает тебя, либо готовит черновик на утверждение.
- Помнит, куда уже откликался, между перезапусками — `data/apply_log.json`, обычный файл на диске, не зависит от памяти чата.

## Требования
- Python 3.9+
- [Claude Code](https://claude.com/claude-code) — вся оркестрация (поиск → скоринг → показ списка → отправка) идёт через агента, а не только скрипты сами по себе
- Реальный аккаунт hh.ru (логин руками при первом запуске — капча/2FA не обходятся)
- macOS / Linux / Windows — браузер на выбор: bundled Chromium (ничего ставить не надо), либо твой Chrome / Edge / Brave

## Установка

```bash
git clone https://github.com/<your-fork>/hh-agent.git
cd hh-agent
./install.sh
```

`install.sh`:
1. создаёт `venv/`, ставит Playwright;
2. спрашивает, каким браузером пользоваться (chromium/chrome/edge/brave), скачивает/регистрирует его;
3. сохраняет выбор в `.env`;
4. ставит скилл [ai-copywriter](https://github.com/mikiarlo3/ai-copywriter) (через `npx skills add`, либо см. инструкцию для Claude Code plugin ниже);
5. создаёт `data/` для резюме/сессии/логов (не коммитится, см. `.gitignore`).

### ai-copywriter вручную (если install.sh не смог)

Как Claude Code plugin:
```
/plugin marketplace add mikiarlo3/ai-copywriter
/plugin install ai-copywriter@ai-copywriter
```

Или cross-agent CLI:
```bash
npx skills add mikiarlo3/ai-copywriter --global
```

## Первый запуск

```bash
set -a; source .env; set +a

# 1. логин руками (капча/2FA)
venv/bin/python scripts/login.py
# в открывшемся браузере залогинься в hh.ru, затем в другом терминале:
touch data/done.flag

# 2. вытащить текст резюме
venv/bin/python scripts/fetch_resume.py
```

Дальше открой этот репозиторий в Claude Code и попроси что-то в духе **"найди вакансии на hh.ru"** — навык `.claude/skills/hh-job-search/SKILL.md` подхватится автоматически и проведёт через весь пайплайн: уточнит критерии поиска, спросит регион/удалёнку, покажет топ-50 на подтверждение перед любой реальной отправкой.

Перед первым прогоном стоит прочитать:
- `docs/RESUME_TIPS.md` — как заполнить резюме на hh.ru, чтобы скоринг и сопроводительные получались точнее, а не общими словами.
- `docs/SEARCH_QUERIES.md` — как подобрать набор поисковых запросов под свой профиль.

## Как это работает (коротко)

```
search_vacancies.py (N запросов)  →  data/vacancies.json
fetch_vacancy_details.py          →  data/vacancies_detailed.json
N × субагент hh-vacancy-scorer    →  data/scored_batch_*.json  (score + черновик письма)
                                   →  топ-50 → data/shortlist.json → ПОКАЗ ПОЛЬЗОВАТЕЛЮ
Skill: ai-copywriter               →  полировка писем для подтверждённых вакансий
apply.py                          →  реальные отклики, append в data/apply_log.json
extract_screening_questions.py     →  data/questions_extracted.json (только если есть needs_manual)
```

Полное описание шагов, селекторов hh.ru и известных граблей — в `.claude/skills/hh-job-search/SKILL.md`.

## Риски — прочитай перед использованием
- Браузерная автоматизация формально нарушает пользовательское соглашение hh.ru. Риск — ограничение аккаунта. Используешь на свой страх и риск.
- Агент никогда не отправляет реальные отклики без твоего явного подтверждения конкретного списка.
- Лимит откликов за один прогон (по умолчанию 10, `HH_MAX_APPLICATIONS`) — анти-бан мера, агент сам его не поднимает.
- Агент не выдумывает факты о твоём опыте и не придумывает ответы на анкеты работодателя (зарплата, готовность к переезду и т.п.) — если этого нет в резюме, он спросит тебя.
- Описания вакансий — недоверенный внешний текст (потенциальный prompt injection). Скорер игнорирует инструкции, встроенные в текст вакансии, и должен сообщать о находке.

## Структура репозитория

```
hh-agent/
├── install.sh                          # установка (venv, playwright, браузер, ai-copywriter)
├── scripts/                            # весь python-код, без личных данных
├── .claude/
│   ├── skills/hh-job-search/SKILL.md   # инструкция для Claude Code — весь пайплайн
│   └── agents/hh-vacancy-scorer.md     # субагент для скоринга вакансий
├── docs/
│   ├── RESUME_TIPS.md
│   └── SEARCH_QUERIES.md
└── data/                                # gitignored: твоя сессия, резюме, история откликов
```
